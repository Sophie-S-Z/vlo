# M0 Foundation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployable, tested skeleton of Vlo: tooling, CI, design tokens, fonts, theme switch, Calm mode, reduced motion, and placeholder routes behind the `VITE_APP_ENABLED` flag.

**Architecture:** One static Vite + React SPA. Providers at the root own theme and motion preferences and write them as `data-*` attributes on `<html>`, so CSS and later effect code read one source of truth. Routes are lazy placeholders. CI runs every check that later milestones extend (guardrails, budgets).

**Tech Stack:** Vite 8, React 19, TypeScript 6.0 (strict), Tailwind 4 (`@tailwindcss/vite`), shadcn/ui, React Router 7 (`react-router`), Vitest 5 + Testing Library + jsdom, Playwright 1.63 + `@axe-core/playwright`, Lighthouse CI, ESLint 10 flat config, Prettier.

**Spec:** `docs/BUILD_PROMPT.md` (sections 1, 5, 7, 8, 15, 16, 21, 22 M0)

## Global Constraints

- TypeScript strict. Free, open-source dependencies only. No analytics, trackers or third-party scripts. Fonts self-hosted through `@fontsource*` packages.
- Theme colors exactly as section 16: Ink bg #0E0D0C, text #EFE8DC, muted #8C857A, accent #E0664B, ink-effect #5B6CFF. Paper bg #F5F1E8, text #1C1A17, accent #C8452D. Night bg #121110, text #E8E2D6, accent #E0664B. Sepia bg #EFE3CC, text #3A2E22, accent #A8432A.
- All colors are CSS variables on `:root` / `[data-theme]`. Landing default theme: Ink. App default theme: Paper.
- Card corners 10 px, 1 px rules, no gradients on interface surfaces. Motion ease token "vlo" = cubic-bezier(0.65, 0, 0.35, 1).
- Layout works at 360 px with a 16 px gutter and no horizontal page scroll.
- `/app/*` renders only when `VITE_APP_ENABLED === "true"`. The landing page links to `/app` only when the flag is on.
- Calm mode or `prefers-reduced-motion: reduce` turns off decorative motion, sound and WebGL (M0: exposes `reduced` and sets `data-motion="reduced"`).
- Initial JS under 250 KB gzipped. Initial bundle contains no three, matter-js, tweakpane, @mlc-ai/web-llm or `src/ai/` code.
- 0 axe violations of serious or critical impact.

## Review Focus

1. localStorage throws (private mode, blocked storage): providers must fall back to defaults and not crash. Test in `MotionPreferences.test.tsx` and `ThemeProvider.test.tsx`.
2. System reduced-motion changes while the page is open: `reduced` must update live. Test with a mocked `matchMedia` change event.
3. Deep link reload on Cloudflare Pages (`/privacy`, `/share/abc`): must serve the SPA. `public/_redirects` with `/* /index.html 200`; e2e opens each route directly.
4. Browsers without View Transitions, or reduced motion on: theme switch must still change theme at once. Test calls `setTheme` with `document.startViewTransition` undefined.
5. Flag value other than exactly `"true"` (empty, `"1"`, `"false"`): app stays hidden. Table test in `flags.test.ts`.
